# Benvenuto nelle note segrete!

Se leggi questo testo, hai superato il login.
Questa è un'area protetta dove puoi caricare i tuoi appunti universitari.

## Come aggiungere nuove note
Basta creare nuovi file markdown nella cartella `content/appunti/`.
Ad esempio: `content/appunti/chimica.md`.

Gli appunti non appariranno in home page né nel feed RSS principale.
